# Clown City v0.1.1 — Critical Playability Fixes

Three independent bugs in v0.1.0 left the game unplayable from a cold boot. All three are fixed in this patch release. No gameplay changes — just making the game actually run.

## Fixed

### Title screen crashed on cold boot
`Level.draw` was called every frame regardless of game state, but `Level.collectibles` is only initialized when a level is loaded. On a fresh page load, the title screen's draw path threw `TypeError: collectibles is not iterable`, which aborted the game loop and left the title frozen on a partial render with no text visible.

`Level.draw` now early-returns when no level is loaded, and the title screen renders cleanly.

### Menu input was silently ignored
`Input.update()` clears single-frame press flags (`justPressed`) at the start of its update so they only register for one frame. But `Input` was registered as the **first** system in the update order, so its clear ran before every consumer could read the flag. Result: `Input.pressed(...)` always returned `false`, which broke **every menu** (title, level select, pause) and the player's dash input.

`Input` is now registered **last** in the system list, so consumers see the flag during their own update and `Input` clears it afterward on the same frame.

### Couldn't walk left on the ground
The corner correction in `resolveCollisions` Pass 2 was intended for **ceiling** bonks — slide past a small ceiling corner instead of hard-stopping — but it wasn't gated on collision direction. It therefore also fired for **ground** collisions, where every frame of walking along flat ground would drift the player's foot across a tile boundary, trigger the correction, and nudge the player horizontally away from the tile center. Left-walking was the most visible symptom; the underlying bug affected both directions.

Corner correction is now gated to `pushDir === 1` (ceiling only). Ground walking is smooth in both directions.

## How to play
Clone the repo, check out `v0.1.1`, and open `index.html` in a browser. No build step required.

**Controls:** Arrow keys / WASD to move, Space / Up / W to jump, Shift / Z to dash, R to restart.
