# Clown City v0.1.0 — Initial Playable Release

First tagged version of Clown City, a momentum-based HTML5 platformer inspired by Ori, Fancy Pants, and N.

## Gameplay
- Momentum-based movement: acceleration, air control, wall sliding, wall jumping, air dash
- Variable jump height (tap vs hold), coyote time, input buffering
- Asymmetric gravity for tighter airborne feel
- Corner correction, squash & stretch animation
- Death, spikes, checkpoints, respawn, hitstop on impact
- LBP-inspired material system with grab mechanic

## Content
- 3 levels including a Circus-themed stage
- Title screen, level select, pause, win screen, transitions
- Moving platforms, sawblades, enemies, one-way platforms, breakable blocks
- Collectibles with save system

## Engine
- Spatial grid for O(1) tile lookups
- Viewport culling
- Cached hazard/goal arrays
- Swap-and-pop particle removal
- Smooth camera with lookahead

## Polish
- Edge rendering, particles, screen flash, HUD icons
- Level timer
- Audio system

## Fixes in this release
- Coyote timer no longer skips the first airborne frame
- Variable jump cut race condition fixed
- Save data now validates array types before loading

## How to play
Clone the repo, check out this tag, and open `index.html` in a browser. No build step required.

**Controls:** Arrow keys / WASD to move, Space / Up / W to jump, Shift / Z to dash, R to restart.
