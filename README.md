# Clown City

A momentum-based platformer inspired by Ori, Fancy Pants, and N.

## Play

Open `index.html` in a browser. No build step required.

## Controls

| Action | Keys |
|--------|------|
| Move | Arrow keys / WASD |
| Jump | Space / Up / W |
| Dash | Shift / Z |
| Restart | R |

## Features

- Fluid physics: acceleration, momentum, air control
- Wall sliding and wall jumping
- Variable jump height (tap vs hold)
- Air dash
- Coyote time and input buffering
- Squash & stretch animation
- Particle effects
- Smooth camera with lookahead
